# License addendum: clubs, associations and private hosting

This addendum grants permissions **in addition to** the [PolyForm Noncommercial License 1.0.0](LICENSE). It does not restrict anything that license allows. If the two seem to conflict, the more permissive reading for the uses below applies.

1. **Clubs and associations.** Use by a club, association, society or other non-profit organisation (for example an Austrian or German *Verein*), whether or not it is officially recognised as charitable, is use for a permitted purpose. This includes running the software for the organisation and its members. Regular membership fees do not make such use commercial, as long as access to the software is not sold separately.

2. **Hosting for others free of charge.** Running an instance for family, friends or members of a non-profit organisation is use for a permitted purpose, as long as nobody pays for access to it or for its operation.

3. **Everything else that earns money is commercial.** In particular, offering the software as a paid hosted service, bundling it with a paid product or service, or using it within a business, needs a commercial license. See [COMMERCIAL.md](COMMERCIAL.md).
